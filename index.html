Qué hace Mi TV

Es una interfaz de inicio instalada de forma privada en un televisor. No es un servicio de streaming ni distribuye películas o series.

01

Accesos rápidos

Abre las aplicaciones disponibles en el televisor desde una pantalla personalizable.

Apple TVNetflixDisney+YouTubeAirPlayHDMI
02

Recomendaciones locales

Con una clave API de TMDB, muestra tendencias, carátulas, sinopsis y catálogos separados por servicio para Colombia.

Los tráileres relacionados de YouTube se muestran como sugerencias de video.

03

Diseñada para TV

La interfaz se controla con el mando a distancia y guarda las preferencias y la clave API en el televisor.

Privacidad y datos

Mi TV es un proyecto personal y no tiene un servidor propio.

Almacenamiento local

La clave de TMDB, las aplicaciones visibles y la caché de recomendaciones se guardan en el almacenamiento local del televisor. Mi TV no recoge ni envía esos datos a un servidor del proyecto.

Fuentes del catálogo

Los datos de películas y series y sus imágenes se solicitan a TMDB. La información de disponibilidad por proveedor procede de JustWatch a través de TMDB. Para ver recomendaciones se requiere una clave API personal de TMDB.

Atribución: This product uses the TMDB API but is not endorsed or certified by TMDB. Disponibilidad de streaming: JustWatch. The Movie Database (TMDB).
